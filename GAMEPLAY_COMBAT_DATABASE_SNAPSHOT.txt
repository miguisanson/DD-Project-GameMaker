**Per-Level Stat Rule (current)**
- Every level-up gives exactly:
  - `+1` unspent manual stat point
  - `+1` auto class stat (Knight STR / Archer AGI / Mage INT / Nobody none)
- Multi-level-up in one EXP grant is supported.

**Player Resource Formulas**
- `StatMod = floor((stat - 10) / 2)`
- `HPGainPerLevel = ceil(HD / 2) + 1`
- `ResourceStatWeight(level) = 1 + floor((level - 1)/4)` (1 for Lv1-4, 2 for Lv5-8, 3 for Lv9-12)
- `max_hp = base_hp + (level-1)*hp_gain + StatMod(DEF)*weight`
- `max_mp = base_mp + (level-1)*mp_gain + StatMod(INT)*weight`
- Then player difficulty multipliers are applied.

**Combat Formula/Flow (current)**
- Initiative: `d20 + AGI mod`.
- Hit check: attacker `(d20 + accuracy bonus)` vs defender `(d20 + dodge bonus)`.
- Damage base: `weapon/skill power + attacker rel stat mod - floor(defender DEF mod / 2)`, min 1.
- Crit chance: `0.05 + luck_mod*0.01 + crit_bonus*0.01`, clamped 5%-50%.
- Final damage order:
  - attacker `dmg_mult`
  - skill multiplier
  - crit multiplier (x2)
  - defender `guard_mult` (and consume guard on hit)
  - difficulty damage multiplier
- Status ticks:
  - Player status ticks after player action (or when stunned and turn is skipped).
  - Enemy status ticks once after enemy turn completes (after action chain ends).
- Enemy action economy:
  - `ENEMY_ACTION_CHAIN_MAX = 3`
  - action budget may be increased by passive `Fury` and set by `Rampage`.
