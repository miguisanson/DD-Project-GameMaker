# Owner import checklist (D94)

Generated by `art/tools/build.py`. Do not hand-edit; re-run the script instead.

Why: the IDE owns the `.yyp`/`.yy` files, so agents cannot create sprites. Code looks each sprite up by name with
`asset_get_index("spr_icons_<category>")` and draws a code fallback until the sprite exists. Do this once per strip, in any order.

## Steps for every strip (about 1 minute each)

1. Asset Browser: right-click the **Sprites** folder, **Create > Sprite**. Rename it to the exact name in the table below (`spr_icons_<category>`; case matters).
2. In the Sprite Editor press **Import** and pick `art/strips/<category>_strip.png`.
3. The **Import Strip Image** dialog appears. Set: *Number of frames* = the Frames column in the table; *Frames per row* = the same number (a single row);
   *Frame width* = 16, *Frame height* = 16; *Offset X/Y* = 0; *Separation X/Y* = 0. Check the preview shows one icon per frame, then **OK**.
   (If your IDE version words these differently, the rule is: one row, 16x16 cells, no offset, no separation.)
4. **Origin**: set the Origin dropdown to **Top Left** (0,0).
5. **Collision mask**: icons are only drawn, never collided with. Do not assign the sprite to any object and leave the default mask. If you want it explicit: Mode = Manual with all four bounds 0.
6. Playback: set the speed to 0 frames per second (it is a lookup table, not an animation). The code picks the frame with `draw_sprite(spr, index, x, y)`.
7. Texture group: leave Default. Save (Ctrl+S).

## After importing

Tell the agent 'strips imported'. The agent removes the code fallback for that category and runs the gate.
If a frame looks wrong in the IDE, the Import Strip numbers are off: delete the frames and import again with the table values.

## Provenance

The final icons in `art/icons/` and the strips are script-drawn pixel art (`art/tools/draw.py`), not AI output. The SDXL images in `art/candidates/` are post-processed candidates only and are not in the strips. All files use exactly #071821 #306850 #86C06C #E0F8CF plus transparency (checked by `build.py`).
