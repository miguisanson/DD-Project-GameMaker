# Owner import checklist (D94, D113, D114)

Generated by `art/tools/build_v2.py` (`checklist.write_checklist_v2`). Do not hand-edit; re-run the script instead.

Why: the IDE owns the `.yyp`/`.yy` files, so agents cannot create sprites. Code looks each sprite up by name with
`asset_get_index(...)` and draws a code fallback until the sprite exists, so the game runs before, during and after the import.
Icons: icon set **v2** (D114). Merchant: **candidate A**, no gold tint (D113). Ten sprites in all: 7 icon strips, the merchant, the card frame.

## Part 1: the 7 icon strips (about 1 minute each)

1. Asset Browser: right-click the **Sprites** folder, **Create > Sprite**. Rename it to the exact name in the table (case matters).
2. In the Sprite Editor press **Import** and pick the strip file from the table (`art/strips_v2/...`).
3. In the **Import Strip Image** dialog set: *Number of frames* = the Frames column; *Frames per row* = the same number (one row);
   *Frame width* = 16, *Frame height* = 16; *Offset X/Y* = 0; *Separation X/Y* = 0. Check the preview shows one icon per frame, then **OK**.
   (If your IDE words these differently: one row, 16x16 cells, no offset, no separation.)
4. **Origin**: Top Left (0,0).
5. **Collision mask**: icons are only drawn. Leave the default; do not assign the sprite to an object.
6. Playback speed: **0** fps (a lookup table, not an animation). The code picks the frame with `draw_sprite(spr, index, x, y)`.
7. Texture group: Default. Save (Ctrl+S).

1. Asset Browser > Sprites > right-click > **Create Sprite**, name it `spr_merchant_idle`.
2. Sprite Editor > **Import > Add from file**: pick `spr_merchant_idle_0.png`, then `spr_merchant_idle_1.png` (two frames, in that order). Do NOT use the `_strip.png` unless you slice it as 2 frames of 16x16.
3. Size 16 x 16. **Origin**: Custom, X 0, Y 0.
4. Playback: 2 fps is the intended look (the game sets the frame itself at 2 frames a second, so this value does not change what you see).
5. Collision mask: Automatic, Rectangle, tolerance 0 (matches the characters; expected box about x 1..14, y 1..15). Texture group Default; 3D and pre-multiply alpha off. Save.

No gold tint any more: the merchant is drawn as it is, with a pulsing gold glow outline (#E8C547, about 1.2 s) added by the code (`Merchant_DrawWorldFx`).
Until the sprite exists the code shows the untinted Nobody sprite with the same glow. The other candidates (B, C, D) stay in `art/merchant/candidates/`.

## After importing

Tell the agent 'sprites imported' (or name the ones you did). The agent removes the code fallback for that category (`python art/tools/gen_icon_fallback.py` after trimming its CATEGORIES list) and runs the gate.
If a frame looks wrong in the IDE, the Import Strip numbers are off: delete the frames and import again with the table values.
