2) Confirmed damage formula (actual code)
- Combat_AttackBonus = StatMod(relevant stat) + weapon.acc
- Combat_AttemptHit:
  - forced miss if defender has force_dodge
  - forced hit if attacker has always_hit
  - else RollD20 + acc_bonus >= RollD20 + Combat_DodgeBonus(defender)
- Combat_Damage:
  - raw = weapon.power + StatMod(attacker relevant stat)
  - mitigation = floor(StatMod(defender DEF) / 2)
  - base = max(1, raw - mitigation)
- Combat_ApplyDamage:
  - dmg starts from Combat_Damage
  - multiply by attacker status dmg_mult (if any)
  - multiply by skill_mult (if provided)
  - multiply by crit_mult (if provided)
  - apply defender guard_mult (and consume consume_on_hit)
  - apply difficulty damage multiplier via Combat_EffectiveDamageMult(attacker)
  - FUN-FIRST passive reduction hook for enemy -> player damage
  - clamp >= 0, subtract from defender.hp

- Timed ATTACK multipliers (Battle_AttackTimingJudge):
  - PERFECT 1.00, GOOD 0.75, OKAY 0.50, BAD 0.25, MISS 0.00
  - In resolve, damage is scaled after Combat_ApplyDamage and refunded difference.
  - FUN-FIRST passive hook can upgrade timing result and add bonus damage.
