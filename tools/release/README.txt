NO HOPE  v1.0
a game by PaleRook
=============================================

A short 8-bit dungeon roguelike for Windows. A run takes about 25 to 30 minutes.
Fight with a timing bar, pick cards, sneak past enemies, find their weak points.
English and Korean.


How to start
------------
1. Unzip the whole folder somewhere you can write to (not "Program Files").
2. Double-click "NO HOPE.exe".
No installer, nothing is added to Windows. Windows 10 or 11, 64-bit.
The game starts in borderless fullscreen. Settings (on the title screen) change the
window mode, the size, the volume, the language and the keys.

If Windows SmartScreen warns about an unknown app: the game is unsigned. Choose
"More info", then "Run anyway".


Controls
--------
                Keyboard                          Gamepad
Move            W A S D or the arrow keys         left stick or d-pad
Confirm / talk  Space, Z or Enter                 A
Back / cancel   Esc or X                          B
Menu            Tab or I                          X or Start
Run (hold)      Shift                             a trigger
Tabs / pages    Q and E                           LB and RB
On the title    Q = profiles, E = Codex           LB = profiles, RB = Codex

Mouse: left click confirms and presses buttons and bars, right click goes back,
the wheel scrolls lists and the credits, sliders can be dragged.

In a fight, a bar sweeps across: press Confirm when the cursor is in the bright
zone. Skills ask for a row of arrows, in order, before the time bar runs out.
Hold Confirm for about two seconds to skip a cutscene.
The keys can be changed in Settings > Controls (keyboard only).


Saves and profiles
------------------
The game saves by itself. Each profile has three save files and its own Codex
and unlocks. Switch or create profiles on the title screen (Q).
Everything is stored in your Windows user folder:

    %LOCALAPPDATA%\DD_Project

(paste that into the Explorer address bar). Copy or back up that folder to keep
your progress. Nothing is sent anywhere; the game never goes online.


Uninstall
---------
To uninstall, delete the folder you unzipped the game into. To remove your
saves as well, delete %LOCALAPPDATA%\DD_Project too. Nothing else is installed.


Credits
-------
CREDITS.txt (also in the game: title screen > Credits) lists everyone whose work
is in NO HOPE. The licences are in the LICENSES folder.
